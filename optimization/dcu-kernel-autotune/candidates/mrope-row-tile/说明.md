# Q/K RMSNorm 与 MRoPE 融合开发记录

旧多行筛选因原生grid覆盖不足且复用输出缓冲造成虚假一致，`rows>1`的旧PASS及性能结论撤销。旧JSON与冻结源码仅供失败调查，不得用于正式收益。单独MRoPE旧多行筛选同样未通过新的覆盖证明。

正式版本位于 `optimization/adaln/qk_norm_mrope.py`、`build-qk-norm-mrope.py`、`qk_norm_mrope_host.cc` 和 `infinilm-qknorm-mrope.patch`。使用九齿定义全部设备数学计算，C++仅做守卫、输出分配及发射；不支持的输入回退既有路径。共享动态N符号证明两个归约输出域一致，保持CUB归约和BF16中间舍入。

正式几何为rows1、warps2、BLOCK128、grid=N*7。新适配器 `adapters/check-h3-fused-mrope.py` 每个case重新初始化输出并检查尾部哨兵，验证动态N、不同步长、位置越界和放大输入；`docs/fused-mrope-dynamic-v2.json`为有效新证据。真实Transformer回归及完整成片通过前不切换默认。
