# Q/K RMSNorm 与 MRoPE 多行合并

复用验收版 `optimization/adaln/qk_norm_mrope.py` 的全部九齿数学表达、BF16 中间舍入和排列；只修改 arrangement 中每个 CTA 的 token 行数以及 warps。研究多行合并能否减少发射小线程块的开销。归约布局变化可能改变 FP32 求和顺序，因此逐位一致检查仍是前提。

微测包含动态行数、不能整除分块的末段、packed/普通 Q/K 步长、广播/三轴独立位置、越界位置及放大输入。主机通过原库 stream 发射，不计入 CPU 编译时间，交替使用 GPU event 计时；结果不作为真实模型收益。正式默认与主机桥不修改，有可靠收益后再做带守卫的原生集成及完整回归。

本轮CPU编译后的语义审查发现，直接修改原arrangement的`rows`仍生成一维`tl.sum`及按行拆分的program域，不会自动变为独立逐行归约。不能直接缩减主机grid。多行版本已在GPU微测前拒绝，构建及发射入口加入拒绝检查；现有编译输出只作失败取证。后续要先在九齿表达/编译链实现分段归约和正确输出域，再讨论性能。此原型没有进入正式模型，也没有造成正式推理错误。
