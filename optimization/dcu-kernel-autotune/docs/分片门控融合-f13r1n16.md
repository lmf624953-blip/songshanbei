# 九齿分片门控融合：完整请求验收与后续方向

2026-11-28，`f13r1n16` 的完整官方A配对均值为 **128.436449 → 120.698043秒**，包含MP4写出，下降 **6.025086%**。49次Transformer合计为 **107.217758 → 101.138358秒**，下降 **5.670143%**。普通默认入口及同一模型实例的A×8/B/C/返回A已经通过；稳定发布目录的实际装载回放已经通过，正式默认已切换至`validated-build/peer-gate-nt-f13r1n16`。

## 实现及适用范围

长注意力的QK→FP32中间分数→softmax/PV拆分已经实测退化：27570 tokens约19.20→44.30ms，新增约42.66GB中间分数往返流量。本轮转而优化真实去噪热点中的投影通信和门控。

当前H3每次Transformer有100处相关投影。新回调保留本地矩阵乘法，按实际InfiniCCL循环rank顺序逐步BF16累加，各卡只计算自己负责的输出分片，在该分片完成原门控/残差，再发布给八卡。九齿表达负责计算，HIP只负责通信、事件、内存及独立校准探针。源码、矩阵乘法、模型层数、50 steps、124帧、seed42及49次Transformer均保留。新增回调仅绑定当前H3两个无bias的RowParallelLinear后继门控。

此实现要求H3在TP rank间复制的残差、相同索引和全量调制表。源码中AdaLN列投影经AllGather重建完整调制表；每层完整输出发布保持复制hidden states不变量。通信校准验证原累加顺序，不承担检查残差复制的职责。独立raw桥的调用者也需满足上述输入前提，其他布局需另行实现和验收。

每个新count/communicator用两组独立有限BF16探针，在所有位置及八卡验证rank环、活动通道、块和尾部。不通过则执行原InfiniCCL和当前九齿门控；不硬编码本节点拓扑为所有环境的资格。

同一八卡驻留模型按`off,on,off,on,on,off,off,on,on,on,on`完成11次独立请求。前两次是双方预热，正式A配对是`(2,3)/(5,4)/(6,7)`。

全部11条成片与此前对应的验收版本逐字节一致；独立PyTorch参考的SSIM为A **93.832013%**、B **99.404123%**、C **99.630047%**，返回A保持一致。每条完整执行49次Transformer及原注意力、归约、SwiGLU等计算；开启候选的每条请求有39200个rank回调/延后投影、4900个融合批次、0回退。A/B/C实际count为148216320/123105024/129357312，三个长度均校准成功。返回A完整请求122.245615秒，也与已验收A逐字节一致。

每5秒整卡显存采样，11请求窗口观察到的最大值为card0 30918MiB、card1 25337MiB、card2/3 17049MiB、card4 33884MiB、card5/6 33858MiB、card7 33762MiB。该采样会漏掉短暂峰值，同实例关闭候选也可能保留候选工作区，不能据此宣称独立进程显存差。每个已校准count按每卡`3*count/8`字节缓存partial/map工作区，校准临时另需每卡`2*count`字节并在校准后释放；不启用跨进程编译缓存。

普通官方入口新进程墙钟为878.74秒，包含完整模型加载和首次生成；120.698043秒是模型常驻、预热后完整请求均值。两种口径分别报告，不将加载时间扣除后的数字称为新进程总耗时。

九齿tile1024、4 warps镜像使用实际运行时rank环参数。原生库SHA256为`2ba472da0249afd0482f6da0648926c8d8864dc59e15fc9fcc807fb7e1eda510`。统一发布入口在新目录完整重建：130个native编译对象逐字节一致，按冻结对象顺序链接后native、主机桥和transport均逐字节一致；九齿镜像的加载区段及映射一致，调试路径可能造成整文件哈希不同。

独立`hipprof --pmc`采集24个`h3_peer_gate_kernel`，覆盖八卡、每卡三次：60 VGPR、48 SGPR、0 shared memory、0 scratch、0% shared memory bank conflict。所有原始字段见[PMC TXT](peer-gate-nt-f13r1n16-basic-pmc.txt)。独立时间线保留在本机validation，路径及SHA见[完整JSON](peer-gate-nt-f13r1n16.json)。profiler中的时间仅用于诊断，性能结论来自无profiler完整配对。

## 复测入口

源码和构建说明见[候选README](../candidates/rccl-sequence-parallel/README.md)。统一入口先冻结前序配置，再重建九齿镜像、通信桥和独立native；每次使用新目录。

```bash
here="$H3_AUTOTUNE_CODE_ROOT/optimization/dcu-kernel-autotune/candidates/rccl-sequence-parallel"
bash "$here/build-peer-release.sh" "$accepted_config" "$new_release" "$xmake_binary"
bash "$H3_AUTOTUNE_CODE_ROOT/optimization/reproduce-public-a.sh" resident \
  "$new_release" "$model" "$new_benchmark_output"
bash "$H3_AUTOTUNE_CODE_ROOT/optimization/reproduce-public-a.sh" single \
  "$new_release" "$model" "$new_single_output"
```

`resident`读取`benchmark.json`的`wall.candidate.mean`，运行8次完整A并排除双方预热。`single`记录新进程普通入口。发布前另用`qualify-peer-gate.sh`完成普通官方入口及A×8/B/C/返回A。`report-peer-benchmark.py`已直接复用本轮11请求的前8条，端到端及全部阶段统计与完整验收报告完全相等，没有为了验证汇总脚本再生成A。

## 后续方向与限制

稳定发布目录已完成第25次真实八卡输入的实际装载回放，输出哈希与已验收版本一致。裁剪到begin/end的2066.891ms窗口中，每张卡均有100个分片门控和100个发布kernel；GPU0注意力937.320ms、GEMM445.334ms、分片门控253.011ms、发布217.981ms、宽归约92.198ms。八卡同时无设备事件合计14.655ms；独立2秒排空等待已排除。该诊断不能代替或混入无profiler完整请求成绩。

值得实测的下一方向是分片门控直接写入八卡最终输出。当前模型回调为输出单独分配Tensor，输入与输出不别名；这为取消partial写回/读回和独立发布kernel提供条件。仍需保留所有输入就绪及发布完成依赖，保留原BF16累加和门控顺序。独立微测必须使用与模型一致的独立输出，不能把原地输入覆盖后得到的错误结果当成收益。预计收益是否超过3%需要实测，尚未实现或宣称有效。

小范围tile/warps微调若只预计带来不足3%的完整请求收益，先记录。残差分片与后继归约/广播的进一步融合属于更复杂的后续研究，需重新审查复制不变量、回退及完整质量，不能仅凭单算子结果推广。当前成果不代表长注意力或整个Transformer已全局最优。
