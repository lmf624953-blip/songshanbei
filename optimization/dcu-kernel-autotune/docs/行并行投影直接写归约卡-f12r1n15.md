# 行并行投影直接写归约卡

归一化后发布的链路对照收益不足，进一步从投影输出检查能否省掉后继门控的远端读取。在 `f12r1n15` 的八卡 BW1000 上，以公开 A 的 `N=27570, M=5376, K=896/1792` 做原 rocBLAS 行并行 GEMM 对照。候选按原 floor 行区间拆分 N，每卡把八个结果区间写本卡或各自的归约 owner。计算和 BF16 输出都保留，直接写入版在每个 owner 的缓冲里为八个来源 rank 分配独立平面。

| 形状 | 切分策略 | 全尺寸对照 | 候选 | 配对耗时变化 |
| --- | --- | ---: | ---: | ---: |
| K=896 | 切分写本卡 | 1.238 ms | 1.838 ms | +48.13% |
| K=896 | 切分直接写 owner | 1.247 ms | 4.034 ms | +223.52% |
| K=1792 | 切分写本卡 | 1.940 ms | 2.574 ms | +32.61% |
| K=1792 | 切分直接写 owner | 1.952 ms | 4.560 ms | +132.59% |

每行分别以相同进程和数据做 39 组无 profiler 交替配对。两种形状的 16 组本卡结果和 128 组来源与 owner 交叉结果全部逐位一致，包含输出尾段哨兵。各对照中位数来自对应配对。微测只衡量原投影，包含主机发射和同步，随后求和与门控均未接入。

直接写 owner 比完整本地写增加约 **2.61–2.79 ms**，而第 25 次真实去噪中现用分片求和与门控累计 252.46 ms，约为每次 **2.52 ms**。即使后续 gate 因数据本地化而变快，这个投影增加量也已用完可见收益预算，所以没有继续接入正式模型。[基线时间线](行分片归一化模型-f13r1n16.md)

独立 K=896 PMC 每卡有一次整尺寸和八次分片 GEMM。整尺寸采用 `WGM8`，分片均采用 `WGM1`。同一分片 kernel 中，本卡写是 0.157–0.161 ms，远端写 0.301–0.333 ms。原始 `L2 cache write unit is stalled` 分别为 2.11%–4.35% 与 67.09%–70.95%。两者均为 **256 VGPR、112 SGPR、64 KiB LDS、0 scratch**。PMC 的时间只用于诊断，性能取舍使用前面的无 profiler 结果。

后续投影优化优先检查现用全尺寸 GEMM 的可选实现，避免重复已完成的库解筛选，保留逐位校验。已验收默认配置为 `peer-sharded-norm-f13r1n16`，公开 A 常驻稳态完整请求 **116.976 秒**。
