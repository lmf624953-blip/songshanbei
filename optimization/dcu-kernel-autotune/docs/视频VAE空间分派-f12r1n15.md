# 视频 VAE 空间分派实测

当前已验收公开 A 的视频 VAE 解码平均耗时 13.504 秒。以同一份 VAE 权重和 768×928、124 帧的诊断形状，在 `f12r1n15` 比较现用两卡时间窗分派和八卡空间 tile 分派。[验收分段](行分片归一化模型-f13r1n16.md)

候选重用原时间窗、空间 tile 坐标、卷积及重叠区混合。每卡完成独立 tile，按原索引收集后调用原拼接函数。测量包含镜像复制、解码、收集、拼接和设备同步。输入使用固定种子的诊断 latent，每侧一次预热，交替完成三组配对。

| 配对 | 两卡时间窗 | 八卡空间 tile |
| --- | ---: | ---: |
| 1 | 13.229682 s | 15.054925 s |
| 2 | 13.592503 s | 12.632175 s |
| 3 | 13.082700 s | 13.918867 s |
| 中位数 | 13.229682 s | 13.918867 s |

逐对降幅中位数为 −6.3914%。两次预热和六次正式样本的完整输出均逐位一致且有限，输出形状为 `[1, 3, 124, 928, 768]`。候选使用更多设备显存，当前端到端收益预算不足，因此归档。由于这组数据没有分别记录卷积、复制和拼接的耗时，不能据此给出各部分的退化归因。
