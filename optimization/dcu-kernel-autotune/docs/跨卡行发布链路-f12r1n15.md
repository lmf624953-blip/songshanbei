# 八卡归一化行的跨卡发布链路

在 `f12r1n15` 用官方 A 投影形状比较四种行发布方式。三种候选让原九齿归一化直接写入本卡完整 GEMM 输入的所属行。它们改变复制的发射方式，沿用原 row ownership、归一化和整尺寸 rocBLAS 投影。按链路分配的 block 只对一个源卡和一个目标卡之间的连续行执行 128 位复制。

| 发布方式 | QKV 流水线墙钟中位数 | QKV 逐对降幅 | FFN 流水线墙钟中位数 | FFN 逐对降幅 |
| --- | ---: | ---: | ---: | ---: |
| 现用标量推送 | 5.269 ms | 对照 | 5.840 ms | 对照 |
| 写本卡所属行，再标量推送七卡 | 5.316 ms | −0.14% | 5.844 ms | +0.02% |
| 128 位分链路推送 | 5.312 ms | −0.58% | 5.882 ms | −0.73% |
| 128 位分链路拉取 | 5.783 ms | −9.13% | 6.368 ms | −8.99% |

每个形状有 39 轮无 profiler 交替配对。计时从归一化开始到八卡投影完成，包含主机发射与同步。两个形状、四个变体和八卡共 64 组检查全部通过。每组检查完整归一化输入位模式、完整投影输出位模式、有限值和尾段哨兵，三个候选的 compact partial 工作区也全部保留哨兵。

## 独立默认 PMC

每个模式各采一次 QKV 流水线，文件均包含八卡各一次归一化、发布和投影，共 24 条。三组采到相同 rocBLAS kernel 符号。以下为每组八条发布记录的原始字段范围。

| 原始 PMC 字段 | 现用推送 | 分链路推送 | 分链路拉取 |
| --- | ---: | ---: | ---: |
| Kernel time | 1.761–1.798 ms | 1.765–1.801 ms | 2.381–2.384 ms |
| VGPR / SGPR | 24 / 48 | 16 / 32 | 16 / 32 |
| Shared memory / scratch | 0 / 0 | 0 / 0 | 0 / 0 |
| L1 cache unit is stalled | 87.26%–87.97% | 92.87%–93.60% | 86.14%–94.19% |
| L2 cache write unit is stalled | 93.03%–93.38% | 94.09%–94.32% | 0.038%–0.048% |
| L2 cache hit rate | 0.040%–0.051% | 26.81%–28.06% | 0.021%–0.023% |

推送版降低寄存器数并提高 L2 命中率，流水线耗时仍基本持平。拉取版把远端写换成远端读，L2 写等待大幅降低，发布耗时约增加 0.6 ms。这些计数用于定位变动后的访存路径，取舍依照独立无 profiler 样本。

三种布局没有达到采用门槛，归档为八卡独立对照。当前正式配置使用已验收的 `peer-sharded-norm-f13r1n16`，官方 A 常驻稳态完整请求 **116.976 秒**。本轮的两个形状是公开 A 的 QKV 和 FFN 投影，跨输入形状及整模型未重新测量。
