# 八卡行发布与投影重叠实测

按最新优化优先级，先测去噪 Transformer 中的归一化行发布与投影。已验收的第 25 次去噪时间线中，GPU0 的 GEMM、行分片求和与门控、行分片发布分别累计约 445、252、218 ms。当前公开 A 的完整常驻稳态均值为 116.975680 秒，其中视频 VAE 解码为 13.504 秒。[验收时间线与分段结果](行分片归一化模型-f13r1n16.md)

本轮在 `f12r1n15` 用生产 A 形状和固定种子的 BF16 输入做独立八卡实验。测量从局部归一化发射到八卡投影完成，包含主机发射和同步，使用原九齿归一化与 rocBLAS 默认投影。每组在八卡逐位校验完整归一化输入和投影输出、检查尾部哨兵后，执行 39 轮无 profiler 交替计时。

| 投影 | 整块发布与 GEMM | 两段发布后串行 GEMM | 同段就绪后重叠 GEMM | 相对整块逐对降幅中位数 |
| --- | ---: | ---: | ---: | ---: |
| QKV，N=27570、M=2688、K=5376 | 5.299 ms | 5.183 ms | 5.146 ms | 2.97% |
| FFN，N=27570、M=3584、K=5376 | 5.748 ms | 5.761 ms | 5.732 ms | 0.35% |

与串行分块相比，重叠使 QKV 和 FFN 分别缩短 0.82% 和 0.53%。按官方 A 的 2401 次有前驱发布的 QKV 和 2450 次 FFN，将两侧中位数差外推约为 0.41 秒，约占已验收请求的 0.35%。投影在独立算子上验证，实际完整请求收益还会受相邻操作影响。

原标量发布分别改为 32、64、128 位读写后，QKV 的逐对降幅为 −0.71%、−0.64%、+0.11%，FFN 为 −0.87%、−0.88%、−0.72%。HIP 跨卡复制使 QKV 从 5.258 ms 增至 8.920 ms，FFN 从 5.748 ms 增至 8.623 ms。所有变体通过八卡逐位与哨兵校验。观测限于当前行归一化布局、复制发射策略及该节点。

独立默认 PMC 核对了完整 QKV 的 8 次 norm、8 次发布和 8 次 GEMM，以及重叠 QKV 的 8 次 norm、9 次发布和 16 次 GEMM。两组 GEMM 采到相同 rocBLAS kernel 名。跨越行分片边界的一张卡为两段分别发布，因而多一次发布。[整块 PMC](publish-gemm-overlap-f12r1n15-full-pmc.txt) · [重叠 PMC](publish-gemm-overlap-f12r1n15-split-pmc.txt)

这些变体均未达到优先采用阈值。整模型候选将继续从其他有明确收益预算的耗时项筛选。第一轮 QKV 使用扩展前的镜像和计时入口，向量写入及跨卡复制使用后续版本。完整记录包含各阶段的镜像哈希，后续版本仍能运行相同三种分块对照。[源码与重建命令](../candidates/publish-gemm-overlap/README.md) · [全部配对与验证记录](publish-gemm-overlap-f12r1n15.json)
