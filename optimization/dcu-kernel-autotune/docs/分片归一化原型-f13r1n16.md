# 分片门控、局部归一化与发布：独立原型结果

2026-11-28，在 `f13r1n16` 找到新的待接入方向：将宽 RMSNorm/indexed AdaLN 放在分片门控之后、发布之前，减少 TP ranks 上的重复归一化计算。独立八卡原型已有可靠的微测收益，**尚未接入真实模型、尚未得到新的端到端成绩，也没有更新正式默认**。当前已验收最佳仍为 `peer-gate-nt-f13r1n16`，已有稳态官方 A 完整请求均值 120.698043 秒。

## 原型如何计算

参考流水线是当前已验收 peer 求和/门控→发布完整 hidden→八卡各自完整 RMSNorm/indexed AdaLN。候选按完整行分配工作：每卡原序求和/门控得到自己的 hidden 行，使用**现用、未修改的归一化设备镜像**处理这些行，再发布完整归一化结果。原始 hidden 只保留本卡拥有的行，供下一次门控残差使用。

这没有物化长注意力的 QK 分数，也没有改变长注意力。求和只改变处理区间，仍用运行时通信校准位置表决定每个元素的 BF16 累加顺序；归一化按完整行执行，保留现用 FP32 归约及 BF16 舍入顺序。

## 数值、依赖与重建

- 两种主机调度均在三个生产长度上通过完整归一化输出、局部 hidden 的 BF16 原始位模式比较；所有未拥有的 hidden 行及输出尾部哨兵保持正确。
- 普通、极小值、大幅值、NaN/Inf 四类输入均另开 GPU 消费者诊断。每次计时外先写入哨兵，再由同 stream 的 GPU 消费者读取发布结果；这些额外读取不计入上表干净性能。
- 每个长度与数值类别均在计时后连续三轮把分片 hidden 用作下一轮残差，归一化输出仍与完整参考逐位一致。这样检查了分片状态确实能够延续，不依赖未拥有区域的旧数据。
- 强制 `NCCL_ALGO=Tree` 后，校准按预期失败；共 **0 fused / 9 fallback**，原 InfiniCCL＋门控＋完整 norm 的输出、消费者和连续残差检查通过。诊断显式恢复被 AllReduce 原地修改的局部输入。
- 最终 split 的主机桥和 HIP transport 独立重建逐字节一致；九齿设备镜像的全部可加载区段、常量和 ELF 映射一致，整文件仅非加载内容有差异。

原型检查的是独立链，不能代替模型中分片 Tensor 生命周期、末层完整物化和回退切换的验证。

## 下一阶段的具体要求

当前 native 源码图已核对 SHA `b3341d79f35b850b2924e383a22100d0250f348cd0859b11cc2dd33c553bea1e`，实际 gate→norm2、FFN gate→下一层 norm1、最后 `norm_out` 的位置已记录。接入模型需要：

1. 独立保存并验证每 rank 当前分片 hidden 的 Tensor 身份、完整形状、有效行、communicator 和生命周期，防止指针复用或跨请求残留。
2. gate 仅生成行分片；indexed norm 回调识别分片输入，处理本卡完整行并发布完整输出。原 GEMM 保持原形状与原计算。
3. 首个 norm1 沿用完整输入路径；最后 FFN gate 之后、`norm_out` 之前物化完整 hidden。不支持的 norm、回退、关闭切换也必须先物化。
4. 验证真实 RMSNorm weight、调制表、索引在 TP ranks 间复制；区分校准成功的分片 hidden 与校准失败的完整 hidden。
5. 实际八卡第 1/25/49 步做逐位与无 profiler 对照，参考必须是当前已验收 peer 版。胜出后再完成官方默认入口、49 次 Transformer、A 稳态配对、B/C/返回 A、质量及内存回归，最终才允许更新默认。

本目录的 C++ 库仍是独立原型，返回语义与普通 gate 回调不同，禁止直接注册到正式模型。完整源码与命令见 [原型 README](../candidates/peer-sharded-norm/README.md)；原始配对、数值、构建、重建、图审查及时间线摘要见 [JSON](peer-sharded-norm-f13r1n16.json)。原始基础 PMC 分别为 [gate](peer-sharded-norm-f13r1n16-gate-pmc.txt)、[norm](peer-sharded-norm-f13r1n16-norm-pmc.txt)、[publish](peer-sharded-norm-f13r1n16-publish-pmc.txt)。
