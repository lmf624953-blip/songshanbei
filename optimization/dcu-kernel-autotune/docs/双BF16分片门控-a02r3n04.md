# 双 BF16 分片门控实测

在 `a02r3n04` 对照现用 `peer-sharded-norm-f13r1n16` 的九齿门控镜像，实测两个相邻 BF16 共享 rank 选择和 32 位读写。输入包含八卡合成张量、运行时 rank 排列、非紧凑 gate 表和完整行分片。后继归一化、发布和真实模型不在本轮范围内。

九组输入覆盖三个生产行数、奇数行尾段、混合 owner、首尾 owner 相同但内部不同的反例、极小值、大幅值及 NaN/Inf。三个候选的 216 项全数组位模式和哨兵检查全部通过。每个 BF16 元素均保持原七次累加、门控和残差的舍入边界。

## 独立默认 PMC

使用 `hipprof --pmc --pmc-off`，预热后分别采集参考与 tile256 各八次发射，核对每组覆盖八张卡。以下为 hipprof 原始字段，范围为八卡最小到最大值。

| hipprof 字段 | 参考 | 双 BF16 tile256 |
| --- | ---: | ---: |
| `kernel time` | 2.395–2.401 ms | 2.390–2.407 ms |
| `vgpr count` | 60 | 24 |
| `sgpr count` | 48 | 48 |
| `shared memory size` / `scratch size` | 0 / 0 | 0 / 0 |
| `processed ALU instructions` | 31.2925–31.3587% | 18.7365–18.8868% |
| `shared memory bank conflict` | 0% | 0% |
| `L1 cache unit is active` | 98.1044–98.5537% | 72.8111–76.6147% |
| `L1 cache unit is stalled` | 3.2569–3.4045% | 5.4858–11.4561% |
| `L2 cache hit rate` | 29.9425–30.5112% | 8.6435–9.6665% |

VGPR 与 ALU 指标降低没有带来可靠时间收益，L2 命中率也随访问策略变化。该组指标不能证明其他门控或访存策略均已最优。[hipprof 默认 TXT 原文](peer-gate-packed-a02r3n04-pmc.txt)

tile256 的独立重建通过可加载 section、segment 映射和 ELF 目标核对。该候选未接入真实模型，不产生新的端到端成绩，正式版本仍为 116.975680 秒的已验收组合。后续从 VAE 的主机发射与多进程时间窗调度验证较大收益预算。
