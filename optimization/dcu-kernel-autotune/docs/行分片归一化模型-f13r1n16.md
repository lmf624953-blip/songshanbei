# 模型级行分片归一化：完整资格与发布检查

2026-11-28，`f13r1n16` 八卡 BW1000 上，本候选已经通过普通官方默认 A、同实例 A×8/B/C/返回 A，以及独立参考质量检查。正式完整 A 从 **122.526417 降至 116.975680 秒，下降 4.530237%**。稳定发布组件已复制并通过静态身份检查；**实际加载 trace/PMC 正在执行，尚未切换正式默认**。当前默认仍为此前已验收的 120.698043 秒 peer 版。

## 改动与边界

原流程在分片求和/门控后发布完整 hidden，再由八个 rank 各自执行完整宽 RMSNorm/indexed AdaLN。新流程先在每卡拥有的完整行上执行现用归一化，再发布完整归一化输出；原始 hidden 仅保留本卡拥有的行，供下一次残差使用。首个 norm1 继续走完整路径，最后 FFN 之后、norm_out 之前物化完整 hidden。

长注意力及其 packed 镜像保持不变。这不是 QK 分数物化拆分；此前该拆分额外产生约 42.66 GB/调用的分数写回与读回，生产长度从约 19.20 退化到 44.30 ms，已经归档。当前成功方向是减少 TP 上重复的归一化，并按实际数据依赖安排发布。

求和仍使用当前 InfiniCCL communicator 两组探针校准得到的每元素循环 rank 顺序，每步 BF16 RNE；门控、残差、完整行归一化与调制保留原顺序。模型桥持有真实 Tensor 引用并匹配指针、形状、rank、stream 和 communicator；复制前提不满足时先物化并回退。异常会唤醒等待 rank 并拒绝继续复用失败进程。具体复制不变量与适用范围见[模型 README](../candidates/peer-sharded-norm-model/README.md)。

## 正式完整请求配对

参考是当前已验收 peer 路径，候选是行分片归一化。两侧在同一模型实例中使用相同新 native、注意力及其他设备镜像；关闭候选时直接注册已验收 peer 与原完整归一化回调。比较标识为 `accepted-peer-vs-sharded-norm`。

普通官方 A 不覆盖 steps/frames/seed/height/width；正式保持 768×928、50 steps、124 帧、seed 42、49 次 Transformer。常驻顺序为 `off,on,off,on,on,off,off,on,on,on,on`，前两次分别为双方完整预热，后三组正式配对如下。

## 规格、质量与多用例

全部 11 条成片与此前对应验收版逐字节一致。A/B/C 对独立 PyTorch 参考的 SSIM 为 **93.832013% / 99.404123% / 99.630047%**。返回 A 完整请求 **117.083437 秒**，成片仍一致。B/C 是完整兼容性回归，不混入 A 配对收益。

开启候选的每条请求均有 39200 个 rank 门控回调、4900 个 peer 批次、4851 个分片 norm、49 次最终物化、392 个首层完整 norm，0 peer/复制前提回退。所有请求完成时 pending 为零、失败状态为 false；注意力、GEMM、归约、SwiGLU 和全部 49 次 Transformer 保留。A/B/C 的 token 行数为 27570 / 22899 / 24062，均覆盖非整除八卡的尾部。

每五秒整卡采样，11 请求窗口观察到的峰值为 card0 31756 MiB、card1 25197 MiB、card2/3 17103 MiB、card4 33938 MiB、card5 33913 MiB、card6 33912 MiB、card7 33816 MiB。采样会漏掉短暂峰值；同实例参考也可能持有候选已分配的工作区，不将其当作独立进程显存差。

普通官方默认 A 新进程 `process.wall=875.75 s`，包含加载、首次生成和退出；官方 Python `total.end_to_end=823.827 s`，首次管线 182.571 s、Transformer 102.582 s。它们与常驻预热后的 116.975680 s 口径不同。未启用 `H3_BENCH_JIT_CACHE` 跨进程缓存优化。

## 数值、源码与重建

真实八卡第 1/25/49 次去噪的视频和音频原始字节 SHA，同时与同实例参考和此前验收 peer 版一致；三步 Transformer 合计中位数改善 3.961250%。独立模型 Tensor 桥另验证开启/关闭/开启、连续残差、尾部哨兵、最终物化、weight 复制不一致回退、Tree 回退以及只有七个 rank 到达时的异常唤醒。

相对当前 peer native，仅 H3 Transformer 的一个编译对象变化，其余 129 个对象一致。独立重建的全部 130 个对象和最终 native 逐字节相同，native SHA256 为 `ba2e14c8e7b4bacf473a4cf4b2be9e6305231313c057c0bd1a9e7a7c1ed5f26e`。模型桥和 transport 独立重建逐字节一致，九齿镜像的加载内容一致。

稳定目录为 `validated-build/peer-sharded-norm-f13r1n16`，复制所有活动运行组件，candidate.env 的实际运行路径均位于该发布目录；原实验目录仅保留测量和来源。发布仍依赖账号已准备的 runtime、相同 DTK/ABI 与模型权重。

## 独立采样与默认选择

实际稳定目录的第 25 次真实模型 trace、两个候选独立 Tensor 桥 PMC 已排在正式计时后串行执行。此处尚不宣称它们完成。实际输出 SHA、统计、加载身份、目标 kernel 数和原始字段全部核对通过后，再将默认切换到稳定目录。

长期目标继续：优先研究真实剩余瓶颈和预计超过 3% 完整请求收益的方向；小收益单项先归档。另有 VMM 分片输入供数能力检查源码，等待本轮全部采样结束后再编译运行，目前没有该方向的性能结论。不将本次成功或有限搜索称为全局最优。
